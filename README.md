# ✊✋✌️ Jokenpô (Pedra, Papel e Tesoura)
Este é um script Python simples e divertido que permite ao usuário jogar o clássico Jokenpô contra o computador. O projeto foi desenvolvido para praticar conceitos fundamentais de lógica de programação e interação com o usuário via terminal.

# 🛠️ Funcionalidades
- Escolha Aleatória: O computador utiliza a biblioteca random para selecionar uma jogada de forma imprevisível.
- Interface no Terminal: Menu interativo para o jogador escolher sua opção.
- Efeito de Suspense: Utiliza pausas dramáticas com a biblioteca time para simular o "JO-KEN-PÔ!".
- Verificação de Resultados: Sistema de condições que valida quem venceu ou se houve empate, baseado nas regras clássicas:
    - Pedra ganha de Tesoura.
    - Tesoura ganha de Papel.
    - Papel ganha de Pedra.
